# Architecture Boundaries

Source-backed discipline: define boundaries and invariants before feature work.

Active invariants:
- Calendar facts are source data; Chad proposes derived blocks but does not rewrite evidence.
- Capability is not authority; protected calendar reality cannot move silently.
- UNKNOWN stays UNKNOWN until evidence resolves it.
- Goal closure requires reality readback, not task completion alone.
- JDK owns private learning truth. Family OS consumes only bridge-safe projections.
- `one-box-mk` is public; do not commit private family email, address, health, school-record, credential, or raw JDK truth.
- No database is required in the current ingestion/decomposition epoch.
- Use durable background jobs only for genuinely long-running work; fast deterministic parsing stays synchronous.
- Do not combine backend/core logic and UI wiring in one feature unit.

Project decisions, not notebook-source mandates:
- Repositories remain separate.
- JDK bridge is versioned and read-only from Family OS for the current epoch.
- Sunday-first calendar is the family domain convention.
