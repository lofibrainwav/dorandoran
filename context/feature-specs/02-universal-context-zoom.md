# G1/G2/D1 — Universal Context + Zoom Slice

Goal: make new Apple, Google, device, learning, map, photo, or future sources plug into one provider-neutral Family OS grammar without hardcoded family identities.

## Canonical flow
Source → Adapter → ContextObservation → 6W1H → evidence/authority → Family lenses → 永 continuity → projection.

## Invariants
- Core logic never branches on a family member display name.
- Universal contracts never branch on Apple/Google provider names.
- Missing 6W1H fields stay missing/UNKNOWN; adapters never invent them.
- A scheduled place is not live presence.
- Capabilities describe what a connection can do; they do not create authority.
- 眞/善/美/仁/孝 are separate evidence lenses, not a composite family score.
- 永 is the continuity/time axis, ordered left-to-right: Past → Year → Month → Week → Today → Now.
- Geographic rendering is presentation; it cannot become place/presence truth.

## First vertical slice

- Today story rail: Now → Next → Change/Watch → Outcome
- Person focus uses person id; specialization is data-driven
- no live GPS claim, route provider, Photos import, or external write action
