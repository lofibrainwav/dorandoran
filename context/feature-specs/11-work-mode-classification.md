# 11 — Digital / Physical / Together

Goal: classify work by actual execution constraints instead of task title heuristics.

Rules:
- DIGITAL requires Chad-executable digital work with no required human decision/approval/physical action;
- PHYSICAL is used when human physical action is the essential work and Chad cannot execute the core action;
- TOGETHER is used when digital execution and human decision, approval, taste, or physical handoff must cooperate;
- explicit calendar child actions preserve their declared mode;
- classification never grants authority to execute.
