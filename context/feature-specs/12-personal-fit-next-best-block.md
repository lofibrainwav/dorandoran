# 12 — Personal Fit + Next Best Block

Goal: recommend 1–3 feasible choices from current capacity without assigning a fixed human ability score.

Rules:
- Total time fit includes task + setup + transition cost.
- High-energy work is not recommended when current energy cannot support it.
- Past patterns are evidence-backed observations, never permanent person scores.
- Observation support/caution stays visible in recommendation reasons.
- Rest is a valid opportunity when explicitly present in the pool.
- Impossible options are filtered; unknown duration remains uncertain, not silently precise.
- Optimization favors useful fit, not maximum task count.
