# Unit 16 — Past Journey Story Projection

## Source law
- Story projection may summarize only structural trip groups and confirmed memory observations.
- It may use explicit capture times and explicit place labels already present in canonical observations.
- It never invents a trip name, destination, route, purpose, emotion, or relationship.
- Canonical evidence/source/place refs remain server/core provenance and never enter the display story.

## Flow
TripGroup + confirmed memories → explicit label collection → privacy-safe story card.

## Acceptance
- deterministic story order follows trip group order
- summary contains count plus only explicit place labels
- missing labels stay absent instead of inferred
- stale/schedule/other-subject observations cannot contaminate a story
- output has no `evidenceRefs`, `sourceRef`, or `placeRef`
