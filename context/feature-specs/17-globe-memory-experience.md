# Unit 17 — Past Journey Globe + Story Experience

## Source law
- The presentation contract composes two independent truths: time-based trip stories and place-based globe clusters.
- Story grouping does not create map coordinates; globe clustering does not create trip meaning.
- Both views come from the same confirmed canonical memory observations.
- The display contract contains no source, evidence, or canonical place references.

## Flow
Confirmed memories → [Past Journey place clustering ∥ explicit-gap trip grouping] → privacy-safe experience display.

## Acceptance
- one provider-neutral entrypoint drives both clusters and stories
- unlocated memories may appear in stories but never as map clusters
- schedule/stale/other-subject observations remain excluded
- output contains no `evidenceRefs`, `sourceRef`, or `placeRef`
- existing globe cluster semantics remain unchanged
