# 20 — Chad Week Insight Projection

Goal: expose a small, privacy-safe weekly read model from reconciled event reality.

Rules:
- Projection never contains Gmail raw text, sender identity, subject, snippet, or source body.
- A resolved fact with superseded claims is a source-backed change, not generic risk.
- A conflict requests RECOVER first; it does not immediately ask a human.
- Cancellation is explicit and visible.
- Start/end changes suggest transition review; location changes suggest route recheck.
- Materials changes suggest preparation; recurrence changes suggest future-occurrence review.
- Proven-tight transition does not become a warning.
- High physical friction can raise an action hint independently from source changes.
- Output is a read model only; it cannot mutate Calendar, Gmail, or Goal state.
