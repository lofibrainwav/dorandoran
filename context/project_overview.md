# Project Overview

Chad Family OS is a Jayden-centered family coordination web app.

Primary timeline truth:
- Jayden primary calendar
- Family Ops calendar

Parent personal calendars remain separate SSOTs and become constraints only when pickup, handoff, physical ownership, travel, or availability matters.

Greenfield goal:
- preserve verified Family OS domain logic
- replace the legacy app shell
- use a current, mutually compatible web stack
- add HyoDo as the fail-closed quality/evidence gate

First product slice:
- static hero shell
- Sunday-first Family Week
- mock data through the verified domain core
- no write actions, DB, Routes, or photo pipeline yet
